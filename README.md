# Tirandor Cartographer — v0.2

Статический local-first редактор карт для D&D, рассчитанный на GitHub Pages и печать.

## v0.2

Версия расширяет MVP в сторону картографии среднего и высокого средневековья:

- библиотека из 36 символов: поселения, замки, башни, храмы, аббатства, руины, мосты, гавани, шахты, лагеря, пещеры, рельеф и dungeon-маркеры;
- декоративные элементы: compass rose, scale bar, cartouche, banner;
- одиночные штампы и brush-режим для массовой расстановки;
- пять картографических тем: Parchment, Monastic, Royal Chart, Siege Draft, Night Ledger;
- импорт пользовательских изображений прямо на карту;
- inspector для позиции, размера и поворота импортированных объектов;
- обратная совместимость с проектами v0.1.

## Архитектура

Без backend и без npm: обычные HTML/CSS/JS, IndexedDB и PWA cache. Проекты экспортируются в .dndatlas.

## GitHub Pages

Deployment выполняется через .github/workflows/deploy.yml. Каждый push в main публикует текущую версию.
