# Tirandor Cartographer — v0.3

Local-first редактор карт для D&D с упором на средневековую картографическую эстетику, печать и отсутствие backend.

## Новое в v0.3

- дороги и реки рисуются свободными сглаженными кривыми вместо только прямых отрезков;
- новый инструмент «Область»: земля/берег, вода, лесной массив, болото, пустошь, граница владения;
- дополнительные символы: рынок, таверна, поместье, гильдия, кладбище, дозорная башня, поле боя, переправа, сады и болото;
- автоматическая легенда по использованным символам;
- координатные подписи сетки;
- профили слоёв: both / player / GM-only;
- экспорт PNG и печати в DM или Player варианте;
- настройки толщины и типа дорог, типа областей и легенды через inspector.

## v0.2

Сохраняются все возможности v0.2: 36 базовых средневековых символов, brush-штампы, пять тем оформления, импорт картинок и inspector.

## Развёртывание

Проект остаётся статическим и разворачивается GitHub Pages workflow из .github/workflows/deploy.yml.
