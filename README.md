# Tirandor Cartographer — v0.4

Local-first редактор D&D-карт с эстетикой средневековой рукописной картографии.

## v0.4

- редактирование узлов свободных дорог, рек, областей и городских стен;
- новый инструмент замкнутой городской стены с башнями;
- средневековая штриховка воды, лесов, болот, полей и городских кварталов;
- береговые штрихи для суши и побережий;
- исторический Portolan overlay: сеть румбов и ветров;
- темы Mappa Mundi c.1300 и Portolan 1375;
- крупное расширение обычных обозначений: городская застройка, ремёсла, сельская местность и инфраструктура;
- новая категория «Иллюминации» с масштабируемыми векторными рисунками: дракон, виверна, морской змей, кит, сирена, грифон, единорог, лев, василиск, горгулья, слон, верблюд, олень, вепрь, волк, орёл, король, рыцарь, паломник, голова ветра, ангел, демон, солнце и луна.

## Историческое направление

Визуальная логика ориентируется на европейские mappae mundi XIII–начала XIV века и портоланно-атласную традицию XIV–XV веков. Это не реконструкция конкретного памятника, а набор инструментов для D&D-карт в соответствующей визуальной грамматике.

## Deployment

GitHub Pages разворачивается автоматически из main. Workflow также выполняет node --check для всех JavaScript-файлов перед публикацией.
