# Tirandor Cartographer — MVP v0.1

Полностью статический local-first редактор карт для D&D. Никакого backend, npm или сборки: `index.html`, `styles.css` и файлы из `js/` можно раздавать как обычные статические файлы.

## Что умеет версия 0.1

- проекты и несколько карт в одном проекте;
- карты типов **Мир / Регион / Город / Подземелье / Battlemap**;
- canvas-редактор с pan/zoom;
- выделение, перемещение и базовое масштабирование объектов;
- инструменты: области/комнаты, стены, двери, дороги, реки, подписи, деревья, горы, поселения;
- квадратная, flat-hex и pointy-hex сетка;
- snapping к сетке;
- слои: активный слой, видимость, блокировка, добавление, переименование и удаление;
- Undo / Redo, Delete, Ctrl+D;
- локальное автосохранение в IndexedDB;
- PWA/offline cache: после первого открытия приложение может работать без сети;
- экспорт и импорт всего проекта одним `.dndatlas` файлом;
- PNG x2;
- печать A4/A3;
- специальный tiled battlemap-режим: **1 клетка = 25,4 мм (1 inch)**, после чего браузер может сохранить результат в PDF.

## Запуск локально

Для локального запуска достаточно любого статического HTTP-сервера.

```bash
python3 -m http.server 8080
```

Затем открыть:

```text
http://localhost:8080
```

## GitHub Pages

В репозитории уже есть `.github/workflows/deploy.yml`; он публикует статические файлы без сборки.

В **Settings → Pages → Source** выберите **GitHub Actions**. После этого push в `main` автоматически публикует новую версию.

## Хранение

Рабочие данные живут в IndexedDB конкретного браузера. Для резервной копии регулярно используйте **«Экспорт проекта»**. Файл `.dndatlas` в v0.1 представляет собой переносимый JSON-контейнер; формат версионирован для последующей миграции.

## Ограничения v0.1

Это первый рабочий MVP. Пока нет Bezier-кривых, текстурных terrain-brushes, библиотеки пользовательских PNG/SVG, fog of war, генераторов городов/подземелий и совместного редактирования.

Следующий логичный этап — v0.2: полноценные кривые рек/дорог, coastlines/polygons, кисти лесов/гор/руин, ассеты и DM/player export profiles.
