# Asset & font sources

## Open SVG pack

Selected vector icons come from Game-icons.net / game-icons/icons.

- Repository: https://github.com/game-icons/icons
- Website: https://game-icons.net/
- License: Creative Commons Attribution 3.0 (CC BY 3.0)
- Included local copy of upstream license: assets/open-icons/LICENSE-game-icons.txt

The bundled files are recolored to a parchment-friendly ink tone and have the default black background path removed. Original authors are shown in the asset label / inspector attribution.

Bundled authors include Delapouite, Lorc, and Caro Asercion.
